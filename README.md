# Day 4 Progress

## Research Paper Review

### Paper Title

Breast Cancer Recurrence Prediction Using Machine Learning

## Topics Learned

* Disease prediction using machine learning
* Clinical and laboratory biomarkers
* Model evaluation metrics
* SHAP analysis
* Decision Curve Analysis (DCA)

## Files Added

* paper/paper1_summary.md

## Key Findings

* AdaBoost achieved the best performance
* Accuracy: 97.1%
* AUC: 0.987
* Important features included CA125, CEA, Fibrinogen, and Tumor Diameter

## Research Gaps Identified

* Small dataset size
* No external validation
* Lack of genetic mutation data
* Possible selection bias

## Key Learnings

* Importance of model evaluation metrics
* Role of biomarkers in disease prediction
* Challenges in healthcare machine learning research

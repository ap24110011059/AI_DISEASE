# Limitations

Although the proposed adaptive framework demonstrated promising performance
for Chronic Kidney Disease detection, several limitations remain.

1. The CKD dataset contains only 400 patient records, which may not fully
represent diverse patient populations.

2. The current implementation relies on retrospective datasets and does not
utilize real-time clinical streams.

3. Clinical validation has not been performed in collaboration with hospitals
or healthcare providers.

4. The adaptive framework is evaluated using simulated sequential batches
rather than true online learning environments.

5. While the adaptive and proactive components improve recall, they introduce
additional false positives that may require further threshold tuning.

6. The proposed system has not yet been deployed as a web or mobile
application.

Future studies should address these limitations through larger datasets,
multi-center collaborations, and prospective validation studies.

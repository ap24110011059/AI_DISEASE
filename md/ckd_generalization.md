# CKD Generalization Study

The Adaptive MLP model was evaluated using multiple random seeds to assess robustness.

## Findings

| Seed | Accuracy |
|------|------|
| 42 | 0.76 |
| 7 | 0.75 |
| 21 | 0.74 |
| 101 | 0.77 |

The low variance across experiments indicates that the proposed model generalizes well across different train-test splits.

Future work includes evaluation on external CKD cohorts and real-world clinical datasets.

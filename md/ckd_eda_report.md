# Chronic Kidney Disease Exploratory Data Analysis

## Dataset Overview

- Dataset: UCI Chronic Kidney Disease Dataset
- Total Samples: 400
- Features: 24
- Target Variable: Classification (CKD / Not CKD)

## Key Findings

1. Serum Creatinine exhibited a strong correlation with CKD.
2. Hemoglobin levels were generally lower among CKD patients.
3. Albumin and Blood Urea showed significant predictive capability.
4. Missing values were present across multiple clinical attributes and were handled using median imputation.

## Class Distribution

- CKD: 250
- Not CKD: 150

## Conclusion

The dataset demonstrates clear separability between CKD and non-CKD classes, making it suitable for machine learning-based disease prediction.
